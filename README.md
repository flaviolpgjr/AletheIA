# AletheIA

AletheIA é uma plataforma em Go + React que utiliza inteligência artificial e dados públicos para analisar a viabilidade de promessas políticas.

O projeto nasce da ideia de aproximar tecnologia, transparência pública e análise crítica, utilizando IA para transformar discursos e propostas em análises mais claras, contextualizadas e baseadas em dados reais.

O nome “AletheIA” é inspirado em *Aletheia*, conceito da filosofia grega associado à verdade e revelação, combinado com “IA” (Inteligência Artificial).

## Objetivo

O objetivo da plataforma é analisar promessas políticas utilizando:

- dados públicos;
- indicadores econômicos;
- contexto social;
- histórico governamental;
- inteligência artificial;
- processamento automatizado de dados.

A proposta não é prever o futuro ou determinar “verdades absolutas”, mas criar uma ferramenta que ajude a visualizar plausibilidade, impacto e coerência de propostas públicas.

## Funcionalidades planejadas

- Análise automatizada de promessas políticas
- Integração com modelos de linguagem (LLMs)
- Coleta e processamento de dados públicos
- Pipeline de scraping e atualização de informações
- Score de viabilidade econômica
- Indicadores sociais e fiscais
- Dashboard interativo
- Histórico de análises
- Comparação entre propostas
- API REST em Go
- Frontend moderno em React
